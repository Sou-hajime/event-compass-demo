# Event Compass Demo

イベント全体・組織・人・日付から同じタスクを見て進める、公開用の操作デモです。

## 主な機能

- タスクカードのドラッグ移動と並べ替え
- 状態別・組織別・人別のボード表示
- 組織図から組織やメンバーへの担当割当
- カード・組織・役割・担当内容の追加と編集
- 操作名・日時・変更前後を確認できる履歴とCSV出力
- 機能の説明、使い方、活用場面

## データについて

かすがい郡上踊りの運営を題材に、公開向けに再構成したサンプルです。人物名・担当・状態・予定・アンケート数値は架空で、実際の運営状況を表しません。個人連絡先、内部資料のURL、元のスプレッドシート、APIキーは含みません。

変更は同じブラウザのlocalStorageに保存されます。別端末・別ユーザーには共有されません。操作名は自己申告で、認証済みの監査ログではありません。GAS・Drive・Googleカレンダーへの書き込みや同期はありません。

## 確認の流れ

1. 上部の操作名を入力します。
2. 「タスク・進捗」でカードをドラッグします。
3. カードの担当欄から組織や人へ割り当てます。
4. タイトルを押して内容を編集します。
5. カードの「履歴」で変更前後を確認します。

「機能と使い方」に用途と操作手順をまとめています。スマートフォンでは状態欄や割当ボタンを使用できます。

## 起動

静的なHTML・CSS・JavaScriptで構成しています。GitHub Pagesではリポジトリのmainブランチのルートを公開してください。ビルドやAPIキーの設定は不要です。
